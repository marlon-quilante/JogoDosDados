# Jogo dos Dados

![](https://imgur.com/4D14Gvx.gif)

## Introdução

Um jogo de sorte onde você disputa com seu computador para ver quem alcança a linha de chegada mais rapidamente.

## Funcionalidades

- **Lançamento  de Dados**: Lance o dado e conte com a sorte para tirar o maior número possível.
- **Computador como Oponente**: Tenha seu próprio computador como oponente para que possa jogar sozinho.
- **Nova Partida**: Possibilidade de iniciar uma nova partida sempre que finalizar a anterior.
- **Avanço Extra**: Avance casas extras ao cair em uma determinada posição sorteada.
- **Recuo**: Recue casas ao cair em uma posição azarada.
- **Lançar o Dado Novamente**: Possibilidade de lançar o dado novamente ao tirar o número 6.
- **Apresentação de Informações** A cada nova jogada é possível visualizar o turno da vez e qual a posição atual de cada um dos jogadores.
